# 角色工坊使用说明

角色工坊是 QtDesktopPet 的独立角色作者工具，图形界面程序为 `QtDesktopPetCharacterStudio.exe`，命令行程序为 `QtDesktopPetCharacterTool.exe`。它将已有素材转换为可导入桌宠的角色包，不生成新动作，也不做 AI 补帧。

## 下载、解压和启动

1. 在版本发布页面另外下载 `QtDesktopPet-CharacterStudio-0.3.0-windows-x64.zip`。普通桌宠安装包不包含工坊和作者编码器。
2. 将作者包完整解压到固定目录，再双击 `QtDesktopPetCharacterStudio.exe`。不要从压缩包内部运行，也不要只复制 EXE。
3. 保留同目录的 DLL、Qt 插件、`encoder/`、许可证及源码材料。作者包已自带 Qt、Windows C++ 运行库、固定 FFmpeg/ffprobe，用户无需安装 Python、Node、FFmpeg 或 Qt。

## 准备哪种素材

| 素材 | 选择方式 | 准备要求 |
| --- | --- | --- |
| 单张透明 PNG | 「选择文件」 | 适合静态立绘，保留完整透明画布 |
| 透明 PNG 序列 | 「选择序列 / 角色目录」 | 一个文件夹放同一动作，按 `000001.png` 等补零编号排序，建议画布尺寸一致 |
| 透明原片 | 「选择文件」 | 支持带透明通道的 ProRes 4444 MOV、VP9 Alpha WebM |
| 绿幕视频 | 「选择文件」 | 支持 H.264 MP4/MOV，需要在参数页启用并调整抠像 |
| WebP 图片或动画 | 「选择文件」 | 使用文件中的帧与时长，转换为输出格式 |
| 已有 v1/v2 角色包 | 「选择序列 / 角色目录」 | 选择直接含 `character.json` 的文件夹，再勾选要转换的状态 |

新素材首先生成 `idle`（待机）状态；工坊不会自动补出说话、思考等动作。若要制作完整多状态角色，先按 [角色包规范](character-package-v2.md) 整理各状态素材，再对已有角色目录进行局部转换。

## 跟着界面完成第一次导出

### 1 · 素材

点击「选择文件」或「选择序列 / 角色目录」填入本地素材。新建角色时填写独立的「新角色 ID」，例如 `my-first-pet`，以便与已有角色区分。

先填 ID，再点击「选择父目录」。例如素材在 `D:\art\source\idle`，已有父目录为 `D:\art\exported`，则「新输出目录」可以是尚不存在的 `D:\art\exported\my-first-pet`。只需预先创建父目录，不要提前创建最终输出目录；修改 ID 后还应检查输出路径是否符合预期。

源目录和输出目录必须互不包含。不能直接输出到素材文件夹内，也不能把包含源目录的上层文件夹当作输出。工坊拒绝覆盖已有目录。

已有角色包应在「已有包：选择要转换的状态」中至少选择一个状态；界面默认选择存在的 `idle`。未选素材、人设、台词、锚点、后继状态 `next` 和原角色标识保留。此时「新角色 ID」不会自动改写已有包的标识。

### 2 · 输出与轻动效

根据目标选择「输出类型」：

| 界面选项 | 适用情况 |
| --- | --- |
| `Animated WebP · 无损编码` | 透明短动画、PNG 序列转换 |
| `Alpha-Matte MP4 · H.264 CRF12` | 跳舞等复杂动作，以视频保存颜色和透明遮罩 |
| 「单 PNG + 轻动效」 | 只含一帧的静态立绘；多帧输入不能直接作为单 PNG 角色导出 |

最大逻辑边默认 512，保持比例缩放，必要时补透明边对齐。输出帧率可先保留自动；「PNG 序列源帧率」要填写素材真实帧率，例如 12。自动模式使用不超过 30fps 的源帧率，超过则默认按 30fps 输出；也可手动指定 1–60fps。可变帧间隔 WebP 使用平均源帧率归一化，不能理解为逐项保留原帧间隔。

透明 PNG 或透明原片无需开启绿幕抠像。绿幕素材请勾选「启用绿幕抠像」，通过「背景取色」选择背景颜色，再调整「相似度」「过渡」「去绿边」。先用预览检查，不确定时保留素材母版并逐项调整。

单 PNG 可按需开启呼吸、拖拽摆动和状态角标。眨眼仅支持静态 `idle`，需要另提供与睁眼图同画布、包含完整角色的闭眼 PNG；勾选「静态 idle 眨眼」后点击「选择闭眼图」。不支持用压扁原图模拟眨眼，也不适用于多帧 PNG、WebP 或视频待机动作。

### 3 · 预览与生成

点击「更新对照预览」，查看「原始素材 · 首帧」与「处理结果 · 首帧」。切换透明棋盘、浅色和深色背景，检查比例、裁边、透明背景和绿幕残留。改变输出或抠像参数后，请重新更新预览。

满意后点击「加入生成队列」，等待状态显示完成。队列串行执行；转换先写入任务临时目录，经过完整离线解码和角色校验后，才输出完整角色目录。

「取消当前 / 清空等待队列」会取消当前与等待中的任务，并清理未完成任务的临时目录；已成功导出的目录保留。错误细节可通过「显示诊断记录」查看。

## 导入桌宠并检查

1. 打开桌宠 **设置 → 角色**，点击「导入角色文件夹」。
2. 选择工坊生成的目录，即直接含 `character.json` 的文件夹；不要选择素材父目录或预览图片目录。
3. 通过验证后，在「当前角色」中选择导入角色并保存设置。
4. 检查完整动作、循环、透明边缘、摸头位置及气泡/胶囊位置。使用静态轻动效时，同时检查桌宠设置中的全局「角色轻动效」开关。

预览仅显示首帧。WebP 的「无损」针对缩放、抠像后的归一化帧；缩放和抠像会改变原始素材。MP4 使用静音 H.264 yuv420p CRF12，存在有损边缘，复杂发丝和半透明材质未必能完美处理。首帧预览不能代替完整动作验收。

## 命令行与转换配方

需要批量处理时，可以在作者包目录打开 PowerShell，先运行依赖自检，再探测、转换和验证：

```powershell
.\QtDesktopPetCharacterTool.exe self-check
.\QtDesktopPetCharacterTool.exe probe --input D:\art\role
.\QtDesktopPetCharacterTool.exe convert --recipe D:\art\task.json
.\QtDesktopPetCharacterTool.exe validate --input D:\art\exported-role
```

示例配方：

```json
{
  "schemaVersion": 1,
  "input": "D:/art/idle-png",
  "output": "D:/art/exported-role",
  "id": "my-character",
  "format": "webp",
  "sourceFps": 12,
  "fps": 0,
  "maxSide": 512,
  "layout": "left-right",
  "key": {"enabled": false, "color": "#00ff00", "similarity": 0.12, "blend": 0.06, "despill": 0.2}
}
```

将配方保存为 `D:\art\task.json`，确认输入存在、最终输出目录尚不存在，再执行上面的 `convert --recipe` 命令。

已有角色目录需增加 `"states": ["idle", "happy"]`，且列出的状态必须已经存在。`format` 为 `frames` 时只接受归一化后单帧，主要用于静态角色。轻动效通过 `effects` 声明，格式见 [角色包规范](character-package-v2.md)；`closedFrameInput` 为闭眼 PNG 本地路径。命令行标准输出为逐行 JSON 进度与最终结果，按 Ctrl+C 取消。

退出码：0 成功、2 输入不合规、3 依赖缺失/哈希错误、4 转换失败、5 产物验证失败、130 取消。

## 限制与离线交付

仅接受本地文件与目录，禁止 URL、播放列表、链接/Junction、越界和嵌套输出。角色包清单 ≤1MiB、≤64 状态、≤1GiB、≤20000 项、≤16 层目录；视频遵循桌宠播放器 300 秒、18000 帧、128MiB、自包含 H.264 等限制，超过明确报错，不静默截断。

作者包中的编码器是独立 GPL 程序，通过子进程调用；许可、源码、补丁/构建参数见 `encoder/`。不要删除依赖材料或仅拷贝 EXE。制作分发包时任何哈希或材料缺失都会失败。工具本身不读写桌宠个人设置、不连接 Agent、不调用网络模型。

实际安装、干净 Windows 和完整人工视觉检查，以本次测试记录中的状态为准；编译成功不能替代这些验收。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 找不到工坊 EXE | 工坊是独立作者包，重新下载并完整解压作者 ZIP，普通桌宠包不包含它 |
| 程序缺 DLL，或命令行自检失败 | 保留完整作者目录、插件和 `encoder/`；优先重新完整解压，不要从不明网站下载 DLL |
| 输出目录已存在 | 换用新的最终目录；父目录可存在，但最终输出目录必须尚不存在 |
| 提示源/输出嵌套 | 将输出放到素材目录之外，并避免让输出包含源目录 |
| 已有角色包没有选状态 | 在状态列表中至少勾选一个实际存在的状态 |
| 单 PNG 导出失败 | 确认输入归一化后只有一帧；多帧动作应选动态 WebP 或视频 |
| 眨眼校验失败 | 确认待机为单张 PNG，闭眼图为同画布的完整角色；已有包转动态格式时，也要核对继承的眨眼配置是否仍适用 |
| 导入角色时提示 ID 冲突 | 新建角色时使用独立 ID；已有包转换保留原标识，应先备份并核对导入提示，不能覆盖内置角色 |
| 预览没更新 | 参数变化后再次点击「更新对照预览」；背景切换只改变展示背景，不重新转换素材 |
| 动画只有待机动作 | 新素材默认只有 `idle`，需要按规范补齐角色包中的其他状态，工坊不会凭空生成动作 |
